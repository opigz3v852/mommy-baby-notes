# 误吞异物怎么办？内镜取出术全程科普

> 更新时间：2026-09-16 (UTC+8)

误吞异物是常见的急诊情况，尤其是儿童和老年人。一旦发生，及时、科学的处理至关重要。内镜下异物取出术作为一种微创手术，具有创伤小、恢复快、成功率高的特点，已成为处理此类情况的首选治疗措施。

一、什么是内镜下异物取出术

内镜下异物取出术是通过口腔插入内镜，进入食管、胃或十二指肠，将误吞的异物安全取出的技术。适用于硬币、电池、鱼刺、小玩具等多种异物，尤其对儿童、吞咽困难或年老体弱者更为安全有效。

若异物卡在消化道且未引发穿孔、大出血等急症，应优先考虑内镜取出。特别是腐蚀性物品（如纽扣电池）或尖锐物（如鱼刺），需尽快处理，以防黏膜损伤或穿孔。

二、术前准备与评估

误食异物后应明确最后进食进水时间，若需内镜下取出异物，要先通过X光或CT明确异物位置、大小及周围组织关系，评估手术难度。手术一般选用全身麻醉，术前需禁食6-8小时，避免术中反流误吸，如遇紧急情况，未达到禁食标准时，可选用气管插管进行麻醉。

三、术中操作方式

根据异物类型，医生会选用异物钳、网篮、圈套器等工具。尖锐异物需调整方向避免二次损伤；较大异物可能需分解后分次取出。

四、术后住院护理

异物取出后，术后的护理也至关重要，它直接关系到患者的恢复情况和是否会出现并发症。术后患者通常需要住院观察24-72小时，具体时间取决于患者年龄、异物的大小、性质、取出过程的难易程度以及有无并发症。

1. 生命体征监测：密切监测血压、心率、呼吸、血氧等，及时发现出血、穿孔或感染迹象。

2. 休息与活动：术后初期建议卧床，病情稳定后可逐渐下床轻微活动，促进胃肠蠕动。

3. 饮食管理：  

   - 术后需禁食禁水6–24小时，让胃黏膜修复。

   - 逐步恢复饮食：  

   - 第一阶段：清流质（温水、清汤、米汤）

  - 第二阶段：流质/半流质（稀粥、烂面条、藕粉、酸奶）  

   - 遵循“少量多餐”，忌生冷、坚硬、辛辣、油腻及含咖啡因或酒精的饮品。

4. 症状观察：  

   - 轻微喉咙或腹部不适属正常，若出现剧烈腹痛、板状腹、呕血、黑便等，需立即报告。

   - 发热、寒战、呼吸困难、吞咽困难加重也需及时处理。

5. 药物治疗：  

  必要时，可以服用胃黏膜保护剂、抑酸药等保护创面，减少胃酸分泌，促进黏膜愈合。

五、家庭护理与康复

部分患者可接受门诊手术，但居家护理同样关键。

1. 饮食过渡

  · 循序渐进：从半流质逐渐过渡到软食，再到正常饮食。

  · 食物选择：选择易消化、温和的食物。如蒸蛋、豆腐、鱼肉、瘦肉末、煮烂的蔬菜等。

  · 烹饪方式：以蒸、煮、炖、烩为主，避免煎、炸、烤。

  · 保持良好习惯：继续坚持少量多餐，细嚼慢咽，避免暴饮暴食。

2. 生活与活动

  · 充足休息：保证充足的睡眠，有助于身体修复。

  · 观察病情：继续留意腹部症状和排便情况，如有异常及时就医。

3. 心理护理与健康教育

  · 心理支持：尤其是对于故意吞食异物的患者（如精神障碍、自杀倾向），家人应给予更多的关心和理解，必要时寻求心理医生或精神科医生的帮助。

  · 安全教育：对于儿童和认知障碍的老年人，家属需加强看护，将小物件（硬币、电池、纽扣、玩具零件等）放在其无法触及的地方。

4. 定期复查

  · 严格按照医嘱复诊，让医生评估恢复情况。

内镜下异物取出术的核心在于及时去除异物，并预防并发症，并尽可能避免开放性手术。日常生活中，我们应细嚼慢咽、专心进食，对儿童与老人加强看护，共同守护消化道健康。
