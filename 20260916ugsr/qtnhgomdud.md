# @杭州人，成人电子预防接种证正式启用！申领攻略来了

> 更新时间：2026-09-16 (UTC+8)

目前，杭州市已经实现成人电子预防接种证落地服务。成人电子预防接种证的申领非常简单，只需在手机上安装“浙里办”APP，就可以在“我的证照”里选择添加“浙江省电子预防接种证”，获得属于自己的电子预防接种证，全程操作不超过10秒。

此后只要出示电子预防接种证，就可以“一码”实现预防接种门诊取号、问询、登记等预防接种服务，实现线下门诊接种全流程无纸化操作。

大家在预防接种中遇到的常见问题，如一人多本接种证、纸质接种证携带不便、疫苗接种信息遗漏缺失等也迎刃而解。

通过杭州市电子预防接种证服务，市民们还可以查看既往接种记录，预约下一次疫苗接种时间，提供接种门诊导航等功能。

后续，杭州将进一步推动智慧化预防接种服务落地，打造无感防疫、自助服务、排队控制、电子签核、智能发苗、扫码接种、屏幕显示、留观提醒和可追溯一体的智慧接种门诊，提升老百姓预防接种的安全性、便捷性、舒适性，通过数字化改造，将预防接种事业推向智慧化新阶段。

1.在预防接种门诊完成建档后的第二天才能在网上申领电子接种证。

2. 电子预防接种证如存在接种记录缺失，可携带纸质接种凭证到接种门诊进行补录。

3. 由于目前数据尚未与外省数据联通，受种者若在外省市接种过疫苗，在下次接种前需提前告知，并携带纸质接种凭证由接种门诊进行补录。

4. 若已经同意协议并授权关联《浙江省电子预防接种证》，但返回“我的证照”找不到《浙江省电子预防接种证》，遇到这种情况需重新下载浙里办APP。

5. 如果出现电子证照扫码亮证突然无法打开，电子证照人脸识别后无法进行下一步，或预防接种应用无法进入，需要退出浙里办APP重新进入。

6. 儿童也可以申领电子预防接种证，目前只支持父母代申领，且接种门诊的接种档案里登记了该儿童的父母身份证号码和手机号码，否则不能代申领。如未登记，可先至属地预防接种门诊登记父母信息。由于目前接种数据只能在浙江省里流通，且省内大部分地市尚未推广电子接种证照，建议儿童接种疫苗时，继续携带纸质版接种证，以便核对。
